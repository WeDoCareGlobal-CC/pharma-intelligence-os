Pharma Intelligence OS
Pharmacovigilance & Regulatory Intelligence Workspace

ICSR case triage, ICH E2B(R3) packages, PRR/ROR signal management, PSUR/PBRER drafts, and live openFDA tracking.

Apache 2.0 ORCID: 0009-0009-8515-2727 Version: v0.1.1 DOI: 10.5281/zenodo.23108387
Star on GitHub ↗ Quickstart → Live App ↗

The Problem

Pharmacovigilance is drowning: 185K+ ICSRs/year to triage manually, E2B(R3) validation is error-prone, signal detection (PRR/ROR) runs on stale data, PSUR/PBRER drafting takes weeks. Regulatory teams need AI that's auditable, not a black box.

Pharma Intelligence OS answers

  • Automated ICSR intake → structured case with human verification gate
  • ICH E2B(R3) XML validation & package builder (FDA/EMA ready)
  • PRR/ROR disproportionality engine with live openFDA sync
  • PSUR/PBRER draft generation from verified case data
  • FDA approval tracking + Orange Book / Purple Book monitoring

Features

Regulatory-grade intelligence with human-in-the-loop verification.

ICSR Triage

Auto-parse FAERS/EudraVigilance/WHO VigiBase. Extract: patient, drug, reaction, outcome. Human verify → lock.

E2B(R3) Builder

Generate compliant XML packages for FDA FAERS and EMA EudraVigilance. Schema validation + business rules.

Signal Detection

PRR (Proportional Reporting Ratio) + ROR (Reporting Odds Ratio) with confidence intervals. Live openFDA sync.

PSUR/PBRER Drafts

Auto-generate Periodic Safety Update Reports from verified case pool. Section templates per ICH E2C.

FDA Tracking

Orange Book (patents), Purple Book (biosimilars), approvals, safety labels, REMS — monitored daily.

Audit Trail

Every action logged: who verified, what changed, when. Tamper-evident for regulatory inspection.

Quickstart

git clone https://github.com/we-do-care-global/pharma-intelligence-os.git
cd pharma-intelligence-os
pnpm install --frozen-lockfile
cp .env.example .env
# Configure OPENFDA_API_KEY, DB_URL, etc.
docker compose up -d
# App at http://localhost:3000
# API at http://localhost:8080
