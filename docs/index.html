The problem

AI tools today are a mess: manifests scattered across providers, secrets sitting in .env files, no rate limits, no audit trail, no cost visibility — and every LLM vendor wanting a different function-calling format.

What PharmaCompanion does

A governed workspace for pharmacovigilance and regulatory intelligence — continuously archived, DOI-linked, ORCID-linked.

ICSR Review

Case-level review with human verification for ICH E2B(R3) packages.

Signal Management

PRR / ROR detection, PSUR / PBRER drafts, signal lifecycle tracking.

FDA Tracking

OpenFDA approval tracking, regulatory timeline visualization.

Audit & DOI

Every release archived via Zenodo; DOI linked to ORCID via DataCite.

Quickstart

Register a tool, store a secret, attach a policy, execute, and watch telemetry.

# Install
npm i -g @we-do-care/agentvault

# Initialise
agentvault init

# Register a tool
agentvault tools register examples/slack-webhook/manifest.yaml

# Store a secret (piped, so it stays out of shell history)
echo "https://hooks.slack.com/..." | agentvault vault set webhook --namespace slack

# Attach a policy (calls are denied until you do)
agentvault policy attach we-do-care/slack-webhook --role agent --max-calls 10

# Run and observe
agentvault serve --port 7420
agentvault tools execute we-do-care/slack-webhook@1.0.0 --arg action=post --arg text=hello
agentvault telemetry live
agentvault audit query
